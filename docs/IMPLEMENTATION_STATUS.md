# 实现状态与验证门槛

截至 2026-10-08。这里区分“源码已实现”“自动化/编译已验证”和“仍需真机验证”，不把代码完成描述为设备验收。

## 已实现

- 鸿蒙 Stage 工程：首页、低碳记录、数据、科普、任务/成就、我的。
- ArkData 本地记录、编辑、删除、积分流水、CSV 导出、备份与恢复。
- 日 / 月 / 年趋势、日期和类别筛选、记录与图表空状态。
- 九类行为均可生成碳排放估算，按来源标注“官方因子”或“参考估算”；积分仍按行动发放，不取决于碳量。
- 节电记录默认选择具体行为并按次数保存；切换到计量模式并确认设备报告的 kWh 时，应用全国 2023 年电力因子。
- 其余八类行为按参考值估算，界面与 CSV 同时给出等级、单位与复算依据；任何一类都可选择只记录行为。
- `DEMO_V1` 历史值保留回看，但被排除在汇总、趋势、构成图和估算导出列之外。
- 拍照/选图、逐次云端上传同意、DeepSeek 网关识别、待核对草稿；识别结果不自动保存。
- “我的”包含本机头像、昵称和网关 URL / 客户端令牌设置；DeepSeek API Key 保留在网关电脑。
- 网页预览网关可在回环地址运行；改为局域网监听时要求配置不少于 24 位的客户端令牌。
- 课程、逐专题练习、任务、徽章、数字兑换和个人记录纪念证书。
- 鸿蒙端家庭碳账户：独立邀请码命名空间、用户确认与系统动态授权、加密 DEVICE_COLLABORATION KV、可信设备 PUSH_PULL、记录更新/删除事件和家庭积分/可核验估算汇总。网页家庭页只做本机演示。

## 仍需实机/外部验证

1. 在真实鸿蒙设备确认相机/系统相册选择器、文件读取、逐次授权、局域网连接和 DeepSeek 待核对草稿流程。照片上传至 DeepSeek 前必须由用户在应用内逐次同意；本地验收不代替该同意。本次只验证网关 readiness，没有上传测试照片或调用模型。
2. 当前没有连接的鸿蒙设备（`hdc list targets` 为空）；需在两台已配对设备上验证家庭同步权限、加入同一邀请码、PUSH_PULL、重复事件、更新/删除、冲突、断网恢复和汇总一致性；在验收前不得宣传为“真机已验证”。
3. 使用个人签名证书安装并验证完整页面、数据库升级、相机和导入导出。当前没有可用签名证书，也未连接鸿蒙真机。
4. 电力估算应在设备能提供可信 kWh 输入的场景下验证；除官方因子以外的生活行为仍不做减排量承诺。
5. 旧版本兑换证书缺少当时统计快照的字段继续显示“—”，不事后猜测补写。

## 发布门槛

- 双设备家庭同步与真实设备核心流程通过，且签名与权限配置符合目标发布渠道。
